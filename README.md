## About Me

I'm a developer passionate about technology, design and problem solving. I have a special interest in **interactive web development** — turning static pages into living experiences, with movement, rhythm and responsiveness to the user.

I work extensively with **GSAP (GreenSock Animation Platform)** to build high-performance animations: smooth transitions, complex timelines, scroll effects with **ScrollTrigger**, and microinteractions that give personality to the interface without sacrificing performance.

I currently build full stack solutions and study technologies focused on front-end, back-end and user experience, always aiming to combine clean code with interfaces that truly engage.
